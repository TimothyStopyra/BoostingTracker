Once connected, clicking Upload CSV on the 2026 Boosts tab will push that file to data.csv in your GitHub repo, so the update goes live for everyone who visits the site — not just this browser.

Create a token at github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens. Scope it to only this repository, with Contents: Read and write permission and nothing else. Treat this token like a password — it's stored only in this browser's local storage and is never sent anywhere except directly to GitHub's API.
